# PtsJs Animations

A gallery of 78 interactive generative animations for the web, built with [Pts](https://github.com/williamngan/pts) and plain JavaScript. Pick one, play with it, change its text, and copy the code.

**Live gallery: https://amanmohdtp.github.io/pts-animations/**

## How to use it

1. Scroll the gallery. Every card is a live preview.
2. Tap the full screen icon on a card to play with it. Move, click, hold, drag or scroll.
3. If a piece has text, edit it in the boxes at the bottom of the full screen view.
4. Tap **View code** to read the source and press **Copy**.
5. Share one piece directly with a link like `https://amanmohdtp.github.io/pts-animations/#Neon%20Sign`.

Each card also tells you where the piece fits in a real website: hero background, loading screen, 404 page, cursor effect, footer and more.

## Good to know

- Previews play on their own. Interaction is only enabled in full screen, so scrolling on a phone never gets stuck.
- Works on desktop and mobile. Animations pause when they are off screen to keep things smooth.
- Typography pieces use the fonts Syne, Fraunces and JetBrains Mono from Google Fonts.

## Run it yourself

No build step. Download the repo and open `index.html`, or serve the folder:

```
npx serve .
```

To host it free, push the files to a GitHub repository and turn on **Settings, Pages, Deploy from branch, main, root**.
